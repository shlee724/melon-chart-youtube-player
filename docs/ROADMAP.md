# 로드맵 — Claude Code에 하나씩 맡길 작업

각 항목의 "프롬프트"를 Claude Code에 그대로 붙여넣으면 됩니다. 위에서부터 순서대로 하는 걸 추천해요.

## ✅ 이미 된 것 (뼈대)
- 멜론 TOP100 불러오기 (교체 / 뒤에 추가)
- 재생목록 편집: 추가·수정·삭제·▲▼·드래그 순서 변경·섞기, 유튜브 주소 직접 지정
- 곡마다 유튜브 자동 검색 → 내장 플레이어 재생 → 끝나면 다음 곡
- 퍼가기 금지 영상 자동 건너뛰기, 볼륨, 이전/다음
- JSON 저장/열기, 종료 시 자동 저장 → 다음 실행 때 복원
- 핵심 로직 테스트 12개

## 1단계 — 실제 환경에서 확인 (가장 먼저!)
- [ ] **멜론 파서 실제 확인**
  프롬프트: `python -m app.melon 을 실행해서 결과를 확인해줘. 곡이 100개 안 나오거나 아티스트/앨범이 이상하면 실제 멜론 HTML을 저장해서 parse_chart 선택자를 고치고, tests/fixtures 샘플도 실제 구조 일부로 바꿔줘.`
- [ ] **유튜브 재생 확인**
  프롬프트: `python main.py 로 실행했을 때 유튜브 플레이어가 Error 153 없이 재생되는지 같이 확인하자. 문제가 있으면 원인부터 설명해줘.`

## 2단계 — 쓰기 편하게
- [ ] 재생 진행바(현재 시간/전체 시간, 클릭해서 이동)
  프롬프트: `player.py 에 getCurrentTime/getDuration/seekTo 를 추가하고 메인 창에 진행바를 만들어줘. 1초마다 QTimer로 갱신.`
- [ ] 반복 재생(전체/한 곡) · 셔플 재생 모드 토글 (`Playlist.next_index(repeat=...)` 활용)
- [ ] 검색창으로 재생목록 필터링
- [ ] 우클릭 메뉴: 재생 / 수정 / 삭제 / 유튜브에서 열기 / 다른 영상으로 다시 검색
- [ ] 키보드: Space 재생·일시정지

## 3단계 — 검색 정확도 올리기
- [ ] `pick_best()` 점수화: "- Topic" 채널, 공식 MV(아티스트명 포함 채널) 가산점 / cover·reaction·1시간·가사 영상 감점
- [ ] 검색어 정리: 제목의 `(Feat. …)` 제거, 아티스트가 여러 명이면 첫 번째만
- [ ] 임베드 금지(101/150) 시 같은 검색의 **다음 결과**로 자동 재시도
- [ ] 곡 수정 창에서 검색 결과 5개를 보여주고 직접 고르기
- [ ] (선택) YouTube Data API 키가 있으면 API 검색 사용 — 단 검색 할당량이 하루 약 100회라 캐시 필수

## 4단계 — 재생목록 관리
- [ ] 여러 재생목록 탭 / 사이드바
- [ ] 멜론 다른 차트(일간·주간·장르) 선택
- [ ] 같은 곡 중복 추가 방지 (melon_id 또는 제목+가수 기준)
- [ ] 유튜브 ID 캐시 파일 공유 (차트를 새로 불러와도 이미 찾은 곡은 재검색 안 함)

## 5단계 — 배포
- [ ] PyInstaller로 Windows .exe 만들기 (QtWebEngine 포함이라 용량 큼, 수백 MB 예상)
- [ ] 아이콘, 앱 이름, 설정 창

## 하지 않을 것
- 유튜브 영상/음원 다운로드, 광고 제거, 백그라운드 오디오만 추출 재생 → 유튜브 약관 위반
- 멜론 자동 주기 크롤링, 멜론 음원 직접 재생
